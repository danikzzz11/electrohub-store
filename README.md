# ElectroHub — Интернет-магазин с витриной и закрытой CRM-админкой

Полнофункциональный современный веб-сервис электронной коммерции с открытой витриной для покупателей и защищенной административной панелью, выполняющей роль полноценной CRM-системы. Подключен к облачной базе данных **Neon PostgreSQL** и развернут на **Vercel Production**.

* **Тестирование:** Автоматизированный E2E-тест (`npm test` / `node test-e2e.js`)

## ✨ Ключевые возможности

### 🛒 Веб-витрина для покупателей
1. **Компактный адаптивный дизайн:** Отсутствие громоздких баннеров, плотная 5-колоночная сетка товаров, чистая типографика.
2. **Навигация в шапке:** Быстрое переключение категорий («Все», «Смартфоны», «Ноутбуки», «Планшеты», «Аудио», «Умные часы», «Гейминг», «Умный дом», «Аксессуары») вынесено в закрепленную верхнюю шапку.
3. **Большой каталог товаров:** 46 позиций электроники и гаджетов с реальными описаниями, характеристиками и фотографиями.
4. **Мультивалютность:** Переключатель валюты в реальном времени (`RUB ₽`, `USD $`, `EUR €`, `KZT ₸`, `BYN Br`, `TRY ₺`, `AED د.إ`).
5. **Интерактивная рулетка стран в телефоне:** При оформлении заказа доступен выпадающий селектор стран с флагами, международными кодами (Россия +7, Казахстан +7, Беларусь +375, ОАЭ +971, Турция +90, США +1, Германия +49 и др.) и маской ввода.
6. **Живой поиск и фильтрация:** Поиск по названию, описанию и характеристикам без перезагрузки страницы.
7. **Интерактивная корзина:** Выдвижная панель корзины с изменением количества товаров, удалением и автоматическим пересчетом суммы.
8. **Оформление заказа (Checkout):** Валидация полей, проверка наличия на складе, генерация уникального номера заказа `#ORD-XXXX`.

### 🔒 Закрытая панель администратора и CRM
1. **Безопасная аутентификация:** Защищенная сессия с токенами в HTTP-only cookies, хеширование SHA-256.
2. **Дашборд со статистикой:** Общая выручка, количество заказов, средний чек (AOV), число клиентов в базе, товары с низким остатком на складе.
3. **Управление каталогом (CRUD):** Добавление, редактирование цен, остатков, характеристик и удаление товаров.
4. **Управление заказами:** Просмотр списка заказов, фильтрация по статусам (`новый`, `в_обработке`, `отправлен`, `доставлен`, `отменен`), смена статуса в один клик с автоматическим возвратом/списанием остатков на складе.
5. **CRM-карточки клиентов:** Автоматическое объединение повторных заказов по номеру телефона, расчет жизненной ценности (LTV), сегментация (`VIP`, `Постоянный`, `Новичок`), полная история покупок и журнал заметок менеджера.

## 📡 REST API спецификация

### Публичные эндпоинты:
* `GET /api/categories` — Список категорий с количеством товаров
* `GET /api/products` — Каталог товаров (параметры: `category`, `q`, `sort`, `in_stock`)
* `GET /api/products/:id` — Детальная информация о товаре и похожие товары
* `POST /api/orders` — Создание нового заказа

### Защищенные эндпоинты CRM (`/api/admin/*`):
* `POST /api/admin/login` — Вход администратора
* `POST /api/admin/logout` — Завершение сессии
* `GET /api/admin/me` — Профиль текущего администратора
* `GET /api/admin/stats` — Сводные показатели аналитики дашборда
* `GET /api/admin/products` — Управление каталогом (поиск, фильтрация)
* `POST /api/admin/products` — Создание нового товара
* `PUT /api/admin/products/:id` — Редактирование товара
* `DELETE /api/admin/products/:id` — Удаление товара
* `GET /api/admin/orders` — Список заказов с фильтрами по статусу
* `GET /api/admin/orders/:id` — Детали заказа с составом позиций
* `PATCH /api/admin/orders/:id/status` — Смена статуса заказа
* `GET /api/admin/customers` — Список клиентов CRM с показателями LTV и сегментами
* `GET /api/admin/customers/:id` — Карточка клиента с полной историей заказов и заметок
* `POST /api/admin/customers/:id/notes` — Добавление служебной заметки менеджера
